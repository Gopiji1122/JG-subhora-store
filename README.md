# JG Subhora Store website

Static website for GitHub Pages and the custom domain https://subhora.in/.

## Deploy on GitHub Pages
1. Extract this ZIP.
2. Upload the **contents of this folder** to the root of your GitHub Pages repository, so `index.html`, `assets/`, `categories/`, `products/` and policy folders sit directly at repository root.
3. Commit and push the files.
4. In repository Settings → Pages, choose the correct branch and root folder.
5. Keep the custom-domain setting for `subhora.in` and verify HTTPS after DNS is configured.
